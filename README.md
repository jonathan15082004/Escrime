# Site de Bell A Nkonen Jonathan

Site personnel présentant Bell A Nkonen Jonathan, escrimeur camerounais spécialisé à l’épée.

## Pages du site

- `Accueil.html` — présentation de l’escrimeur
- `Escrime.html` — profil
- `palmares.html` — palmarès et résultats
- `galerie.html` — galerie de photos
- `Armes et cibles.html` — présentation des armes et de leurs cibles

## Ouvrir le site

Ouvre `Accueil.html` dans un navigateur Internet. Pour que les images s’affichent, conserve les dossiers de photos à côté des pages HTML.

## Publication

Le site est composé de fichiers statiques HTML. Il peut être hébergé sur un service comme GitHub Pages. Après la publication, vérifie que les liens entre les pages et les chemins des images fonctionnent.
